# ADORA Website Design Blueprint v1.0

A production-oriented **design specification**, not an implementation or claim that the Windows repository has been modified.

## What is included

- `01_DESIGN_BLUEPRINT.md`: design rationale, information architecture, layout, tokens, accessibility, motion, data truth, future acceptance criteria.
- `02_DESIGN_TOKENS.json`: proposed original Adora design token source of truth.
- `03_INFORMATION_ARCHITECTURE.md`: sitemap, homepage copy, navigation, API and fallback model.
- `04_QA_ACCEPTANCE_MATRIX.md`: objective quality gates.
- `05_CODEX_IMPLEMENTATION_PROMPT.md`: the next, bounded Web Design 0.2 coding assignment.
- `06_SOURCE_NOTES.md`: references and copyright boundary.
- `07_HOMEPAGE_CONCEPT.html`: **standalone static layout concept**, not production homepage or repo code.
- `08_HOMEPAGE_CONCEPT_DESKTOP.png` and `09_HOMEPAGE_CONCEPT_MOBILE.png` if generated: local browser captures of the concept.

## How to use

1. Read `01_DESIGN_BLUEPRINT.md` and review `07_HOMEPAGE_CONCEPT.html` for section hierarchy.
2. Use original/approved imagery and the existing ADORA catalog schema when coding.
3. Confirm Phase 1.2 closure and current API process state.
4. Send `05_CODEX_IMPLEMENTATION_PROMPT.md` to Codex at the ADORA repository root.
5. Review resulting screenshots and acceptance matrix before approving changes.
